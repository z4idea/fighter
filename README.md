# 蓝色先锋 · Three.js 格斗训练场

本地可运行的第一版格斗游戏。读取已归档的原创角色，不需要登录 Meshy，不依赖在线模型链接。

## 启动

在 PowerShell 中执行：

```powershell
Set-Location D:\fighter
npm install
npm run dev -- --port 5173 --strictPort
```

打开 http://127.0.0.1:5173/ 。本机已使用 Node.js 20.16.0 运行验证。不要直接双击 HTML，GLB 必须通过本地 HTTP 服务加载。

## 操作

| 操作 | 按键 |
| --- | --- |
| 左右移动 | A / D 或方向键 |
| 跑步 | Shift + 移动 |
| 右直拳 | J |
| 右直踢 | K |
| 保持防御 | 按住 L |
| 冲刺 | 空格，可配合移动方向 |
| 暂停 / 继续 | P 或 Esc |
| 重开 | R |

触屏设备提供移动、攻击、防御、冲刺按钮。窄屏自动调整镜头，横屏更便于观察距离。离开页面或窗口失焦会自动暂停；回来后点击继续。

开始页可以选自由对练（AI 对手）或木桩练习（静止目标）。每局 60 秒、100 血，攻击需要靠近对手。直拳伤害 8，踢腿伤害 14，防御减伤 80%。每次攻击最多命中一次，攻击和受击期间存在恢复时间。

## 文件结构

- `src/main.ts`：页面、开始/暂停/结束流程、HUD、动画帧与模拟子步。
- `src/input.ts`：键盘、触屏输入与失焦清理。
- `src/game/combat.ts`：移动、边界、攻击窗口、防御、击退、AI、计时与胜负。
- `src/game/fighter.ts`：GLTFLoader、独立骨骼克隆、动作切换、横向偏移处理。
- `src/game/arena.ts`：平台、灯光、阴影、镜头、火花和冲击环。
- `src/game/sound.ts`：本地合成命中音效，可关闭。
- `src/style.css`：中文 HUD、开始界面与触屏布局。
- `tests/combat.test.ts`：关键战斗规则。
- `assets/characters/azure-fighter/2026-10-14-v2/models/character.glb`：运行时角色文件；两名角色共享几何和纹理，骨骼与动画状态独立。

角色档案、提示词、模型阶段与备份详见 `assets/characters/azure-fighter/2026-10-14-v2/README.md`。原归档和 ZIP 不修改；动作偏移只在内存中的片段副本上处理。

## 检查

```powershell
npm run check
npm test
```

按本次用户要求只做 TypeScript 静态编译，不执行生产构建。另有 8 个必要战斗规则测试：单次伤害、距离、防御、暂停、重开、边界间距、木桩与结束后的输入限制。

开发预览已观察到两个角色、材质、骨骼动画和训练界面，并用实际键盘操作观察到双方血量变化和踢腿命中反馈。这是开发预览与关键规则验证，不代表完整性能测试、跨设备测试或参考视频质量验收。

## 当前边界

对手暂时复用相同角色，用紫色调和地面标识区分。受击、防御、倒地使用已有待机动画加姿态/特效叠加，尚无专用动作。没有联网、跳跃、复杂连招、能量大招、布料模拟。模型约 3.1 万三角面，限制像素比与阴影分辨率以控制首版负担；实际帧率仍需在目标设备上评估。

直拳与踢腿的伤害窗口按本地动作中右手/右脚最大前伸时刻定位。横向根位移归零，保留高度和骨骼旋转，以减少切换动作时跳位；脚滑与过渡姿态仍可后续调优。
